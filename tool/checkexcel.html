● Excel File Tools

Xem, chuyển đổi và xử lý file Excel thật — ngay trong trình duyệt

Tải file .xlsx / .xls / .csv lên để xem nội dung, đổi định dạng, hoặc chạy các tiện ích như xoá trùng lặp, sắp xếp, gộp file. Không có công cụ nào ở đây tải file của bạn lên máy chủ — mọi thứ chạy bằng JavaScript ngay trên máy bạn.

🔒 File không rời khỏi trình duyệt của bạn

Chỉnh sửa Excel

Tải file lên hoặc tạo một bảng tính trống mới, sửa trực tiếp trong bảng (bấm vào ô để gõ), dùng công thức kiểu Excel, thêm/xoá dòng hoặc cột, tìm kiếm và sắp xếp theo cột, rồi tải kết quả về máy.

–
ƒx
Ô có công thức được tô xanh và hiển thị giá trị đã tính (dùng engine tính công thức HyperFormula chạy ngay trong trình duyệt). Bấm vào ô hoặc xem thanh công thức phía trên để thấy công thức gốc. Khi đang gõ công thức (bắt đầu bằng =), bạn có thể bấm hoặc kéo (quét khối) qua các ô khác để tự động chèn tham chiếu ô (A1) hoặc vùng (A1:C5) vào đúng vị trí con trỏ — giống thao tác trong Excel. Hỗ trợ hơn 400 hàm kiểu Excel; một số hàm rất hiếm hoặc công thức liên quan đến định dạng/ngày tháng phức tạp có thể không tính chính xác 100% — khi đó Excel sẽ tự tính lại đúng khi bạn mở file đã tải xuống.
